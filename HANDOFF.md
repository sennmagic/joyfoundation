# HANDOFF

## PROTOCOL
1. Read `HANDOFF.md` (and `AGENTS.md` if present) before acting.
2. Builder (Claude), after a change: update `CURRENT STATE`; add a `REVIEW QUEUE` item (files + what to check) tagged `NEEDS REVIEW`.
3. Challenger (Codex): review the diff / run QA; write `[Blocker]` / `[Warning]` / `[Pass]` findings with file:line + a concrete failure scenario; re-tag `REVIEWED`.
4. Builder: fix every `[Blocker]`, reply, then `DONE`.
5. Disputes: each side argues once under the item; if unresolved, tag `FOR USER` — the human breaks the tie.
6. Neither tool, without explicit human approval: deploys, pushes, runs `git merge/pull/stash`, runs a DB migration on a shared/prod database, or changes SSH/secrets.
7. Sign log entries `— Claude` / `— Codex` with the date.
8. Fallback when one tool is unavailable: the available tool does both jobs and logs `SELF-REVIEWED (solo)`.
